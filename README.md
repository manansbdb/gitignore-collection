## Install / Instalação

### 1) Clone

```bash
git clone https://github.com/manansbdb/gitignore-collection.git
cd gitignore-collection
```

### Use / Usar

```bash
cp gitignore/Node.gitignore .gitignore
```

### Requirements / Requisitos

- `git`
- No paid services required / Sem serviços pagos
