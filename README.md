# Gitignore Collection / Coleção de .gitignore

## Overview / Visão geral

**EN:** Curated `.gitignore` presets for Node, Python, Go, and Rust.

**PT:** Presets curados de `.gitignore` para Node, Python, Go e Rust.

## Files / Ficheiros

| File | Stack |
|------|-------|
| `gitignore/Node.gitignore` | Node.js / npm / yarn / pnpm |
| `gitignore/Python.gitignore` | Python / venv / pytest |
| `gitignore/Go.gitignore` | Go modules |
| `gitignore/Rust.gitignore` | Cargo / Rust |

## Usage / Uso

**EN:** Copy the relevant file to your repo root as `.gitignore`, or merge sections.

**PT:** Copia o ficheiro relevante para a raiz do repo como `.gitignore`, ou funde secções.

```bash
cp gitignore/Node.gitignore .gitignore
```
